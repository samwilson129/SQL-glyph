# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** option in the repository's Security tab to contact the maintainers privately.

If private vulnerability reporting is unavailable, contact the maintainers through their GitHub profile and request a private channel before sending technical details. Include the affected version, impact, and reproduction steps; avoid attaching real credentials or sensitive SQL.

## Scope

SQL Glyph processes SQL locally and does not connect to databases or execute queries. Vulnerability reports involving unsafe local file access, unintended command execution, dependency risks, or disclosure of local SQL are in scope. Please allow maintainers time to investigate and prepare a fix before public disclosure.
